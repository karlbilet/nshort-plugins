# 红果 JS 插件 1.3.0

N果「设置 → JS 源插件」导入 `hongguo-1080.js`，手动启用后点击「浏览」。普通账号只要已获红果源权限即可使用；剧集保持独立插件身份，账号与同步继续由 N果管理。

**需要 N果 0.1.0 构建 32 或后续包含 CENC 插件契约的版本。** 旧 App 仅支持 URL/quality，更新 JS 无法补齐宿主的密钥传递。App 安装包见 [N果公开发布仓库](https://github.com/karlbilet/nshortapp-releases/releases)；iOS 通过 TestFlight 更新。插件与 App 需要配套使用。

## 1.3.0 更新

- 声明真人剧、漫剧、AI剧三个模块；配套 App 可在独立「插件」页显示入口。旧 App 仍可使用默认目录，不会自动获得模块界面。
- 搜索优先复用内置红果的名称 JSON 检索，只接受含有效剧集 ID 的剧名记录，保留海报和集数。有匹配时直接返回；无匹配或接口不可用时再尝试公开网页，并核对查询词与成功标记，防止把校验页当作空结果。
- 修复「加载更多」重复第一页：按每页 18 条推进 offset，第 2 页起使用续页请求类型；切换模块和重新搜索仍从第一页开始。
- 不增加域名权限或账号要求，原插件 ID、收藏/进度身份、1080p 候选及 CENC/弹幕流程保持兼容。

已安装者可使用「检查更新 → 一键更新」，或从原 Raw 地址重新导入覆盖更新，启用状态由配套 App 保留；插件版本应为 **1.3.0**。不需要删除插件，不影响已有收藏和进度。

## 1.2.0 更新

- 补齐 `danmaku` 方法，按当前分集和播放时间段请求红果评论接口，返回 `episodeId/startMs/nextMs/items`，不再固定返回空列表。
- 使用与内置红果一致的评论专用 Gorgon/Argus/Ladon 签名；播放签名保持独立。无需新增域名权限，不传 N果账号或 Cookie。
- 过滤串集、隐藏、重复及超出时间段的内容，清洗控制字符并保留最多 90 条、每条 180 个 Unicode 字符。支持上游 `next_query_danmaku_list_time` 和 cursor 时间段回退；真实错误不会伪装成成功的空弹幕。
- **弹幕显示需要 N果构建 33 或后续包含插件弹幕会话修复的版本。** 构建 32 已支持高清播放，但从插件浏览进入播放时没有传入账号弹幕会话。tvOS 同时修复插件弹幕分页覆盖范围。

## 1.1.0 更新

- 参考内置红果，先请求普通 `/novel/player/multi_video_model/v1/`，无可用候选再试 preload，最后使用受限网页公开回退。每次仅提交当前分集的一个 ID，不批量请求整剧。
- 高清参数放在 `biz_param`，包括 `need_all_video_definition:true`、`video_platform:1024`；播放请求补齐设备/播放器查询参数及签名。
- 使用与内置 `hongguoContentKey` / Swift `ContentKey.decode` 一致的算法解析 `spade_a`，以合成向量验证。选择最高可用分辨率，同档优先 H.264；跳过 bytevc2 和无效密钥，不再跳过全部加密档位。
- 支持 Base64 媒体地址、同档备用地址及较低档候选，每个 URL 独立携带对应的 CENC 密钥。
- 声明官方模型实际返回的 `v3-reading-videocdn302.qznovelvod.com`，保留 `p3-reading-sign.fqnovelpic.com` 海报主机；详情页也返回海报。

## 契约与播放

旧的 `{url, quality}` 明文插件继续可用。加密候选增加 `cencKey`：**恰好 32 个十六进制字符的 AES-128 内容密钥**；未加密候选不传此字段，不传空字符串。`variants` 是最多 16 个同结构、不可嵌套的备选，密钥不能在候选之间共用或继承。

App 校验精确主机和密钥格式，再交给现有的播放/解密流程。Flutter 五端使用既有原生播放器解密选项，原生 tvOS 使用既有 `MediaDescriptor`、本机媒体准备及 Bento4。脚本不处理媒体二进制，不保存内容密钥，不接收账号凭证，也不能设置任意请求头、文件路径或播放会话。

目录与详情继续使用既有接口，搜索增加已有红果域名上的名称 JSON 接口；App 仍对插件海报使用 HEIC 兼容转换。未声明图片只显示占位，未声明视频被拒绝。根域的可信分类不等于子域通配；服务端增加 CDN 时需核实后更新精确清单。

## 画质与限制

1080p 取决于源站实际返回的可用候选，不伪造清晰度。App 候选全部不可用才回退同集网页，网页回退可能只有 360p；继续检查剧集/分集身份和免费试看范围。未知密钥版本和不支持的编码不会交给播放器尝试。

目录按现有 page 契约逐页加载，固定最新排序，每页 18 条。名称检索受上游返回数量上限影响；网页回退仍依赖公开页面结构，不承诺完整全文搜索。多季方法仍是空结果。弹幕取决于源站实际返回，空时间段不会生成虚假弹幕。画中画继续受宿主现有加密媒体支持范围限制，本次不新增加密 PiP 能力。

## 验证

```sh
node --test hongguo/hongguo-1080.test.mjs
```

Node 用例使用合成响应，不访问真实源站或图片；插件运行代码没有 Node 模块依赖。覆盖内置合成密钥向量、Base64 URL、加密 1080p 优先、候选配对、无效密钥、未声明主机、错误分集、旧明文行为及网页回退；新增 7 组内置评论签名向量、23 组弹幕解析向量、分页请求和错误边界。`fixtures/` 来自 N果现有合成契约，不含真实账号、源站响应或媒体密钥。

NShortApp 仓库另有 Go QuickJS、Go/Swift 契约和播放桥回归，以及普通账号 iOS 模拟器的海报、同步与实际分辨率验收。记录：`docs/acceptance/js-plugin-cenc-2026-10-22.md`。单元测试或 tvOS 编译不替代其他平台/真机验收。
